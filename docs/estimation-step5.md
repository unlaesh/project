## Какие значения записаны

В существующее числовое поле **Estimate** перенесены ожидаемые трудозатраты E для всех **34 карточек MVP** из [расчёта PERT](pert-step4.md). У остальных **24 карточек** сохранены относительные оценки [пункта 3](estimation-step3.md). Идеи #58 и #59 остаются вне текущего объёма, их Estimate не заполнено.

Единица — **командные человеко-часы полного объёма карточки**. Для 25 открытых задач MVP это плановая оценка, для девяти закрытых — отдельно обозначенная ретроспективная модель. Закрытые карточки не переоткрывались и не добавлялись в будущую нагрузку. Эти значения не являются фактическими затратами или измеренным остатком частично выполненной работы.

Источник O/M/P и точных E сохранён без изменения в [pert-step4.json](pert-step4.json). Исходная относительная шкала сохранена в [estimates-step3.json](estimates-step3.json); эталон этой шкалы #28 остаётся равным 4 ч. Его текущее Estimate после PERT — **4,17 ч**.

Каждое E округляется независимо до **двух знаков после запятой**, по правилу `ROUND_HALF_UP`, из точной дроби, без промежуточного округления. Это формат числового результата, а не утверждение о точности прогноза до сотой часа.

## Представление Estimates

Создана отдельная табличная вкладка **[Estimates](https://github.com/users/unlaesh/projects/1/views/6)**:

| Настройка | Значение |
| --- | --- |
| Тип | Table |
| Сохранённый фильтр | `estimate:>0` |
| Сортировка | Estimate по убыванию — трудоёмкие задачи сверху |
| Видимые поля | Title, Assignees, Status, Milestone, Priority, Estimate |
| Группировка | Отсутствует; сортировка общая для всех строк |
| Соответствующих фильтру карточек при проверке | 58 |

Числовой фильтр оставляет оценённые задачи текущего объёма. Представление включает открытые и закрытые карточки, чтобы проверить заполнение всех оценок; поэтому сумма всех его строк не равна будущей нагрузке. Для просмотра только открытых задач можно добавить `is:open` к фильтру, а для первого этапа — `milestone:MVP`.

Существующие Backlog, Priority board, Team items, Roadmap и My items сохранены без изменения. Создание представления не меняет статусы карточек, приоритеты, исполнителей или даты.

В пункте 4 сумма точных E открытых задач MVP равна `1379/6 = 229,833333…`, то есть **229,83 ч** при округлении итога. Здесь сначала округлены отдельные карточки, поэтому их сумма в Project — **229,82 ч**. Разница **0,01 ч** вызвана только порядком округления. По всему составу MVP аналогично: **296,83 ч** из точных E и **296,82 ч** по полям Project. Произвольная карточка ради совпадения итогов не корректировалась.

Для следующего расчёта общего резерва исходные суммы сохранённых Estimate — **515,82 ч по всему составу** и **448,82 ч по открытым задачам**. Ретроспективные 67 ч не относятся к будущей нагрузке. Эти суммы ещё не являются календарным планом или подтверждением выполнения к 15 декабря.
